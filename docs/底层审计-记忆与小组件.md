# 底层审计：记忆与小组件

本批基于 develop 的 db0bfcf；没有推送或更改 main。

## 修改文件

- `src/App.tsx`：将记忆整理接入现有聊天代理、模型、线路和订阅解析，翻译复用相同辅助请求入口。
- `src/MemoryPanel.tsx`、`src/memoryLocalOrganize.mjs`、`src/memoryLocalOrganize.d.mts`：接入本地整理和记忆库整理，按助手隔离策略与进度；校验模型输出、来源及写入结果，候选整理不提前归档原记忆。
- `src/memoryModels.mjs`、`src/memoryModels.d.mts`：按助手保存模型配置，读取旧配置；向量请求使用已有原生直连通道。
- `src/backups.mjs`：记忆分类备份及恢复包含各助手的整理和模型配置。
- `src/RoomWidgets.tsx`：统一小组件写入队列，关闭前完成待保存修改，避免陈旧回调及覆盖标题。
- `tests/local-memory-organize.test.mjs`、`tests/backups.test.mjs`、`package.json`：覆盖记忆隔离、真实本地保存、异常、来源和分类备份。

## 清理

移除记忆整理内独立构造聊天代理请求的旧路径，改由注入的统一辅助请求入口完成。旧全局配置仅作为迁移读取，保留以保护用户历史设置。
