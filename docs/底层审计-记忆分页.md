# 底层审计：记忆分页和助手隔离

- 修改 `src/localBackend.mjs`：本机记忆列表支持与服务器一致的状态筛选、分页和稳定排序，避免固定截断前 100 条。
- 新增 `src/memoryPages.mjs`、`src/memoryPages.d.mts`；修改 `src/memoryGovernance.ts`：记忆页面按页获取，不把部分结果显示为全部；分页不推进或异常时明确报错，并拒绝其他助手的记忆。
- 记忆与自动整理状态的异步请求加入序号和卸载保护，切换助手时较慢的旧请求不能覆盖当前助手视图。
- 修改 `tests/local-backend.test.mjs`，新增 `tests/memory-pages.test.mjs`、`tests/browser/memory-switch.html`，更新 `package.json`。覆盖超过 100 条本机记录、超过一页记录、失败和重复分页、跨助手数据拒绝、浏览器中旧请求迟到。
- 删除记忆页面单次请求固定读取前 100 条的旧实现；无用户数据删除。
- 610 项自动化测试通过，TypeScript 和 Web 构建通过；Chromium 实测旧助手请求迟到不覆盖新助手。真实 Android 和真实模型未验证。当前聊天召回路径仍只读取首批活动记忆，后续需单独优化，不能把分页修复宣称为全部记忆召回已完成。
