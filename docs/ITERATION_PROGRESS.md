# 栖间唯一迭代版本 · 开发进度

> **唯一迭代分支：`feature/next-version-only`。**
>
> 本分支从 `main`（49 版）建立，是栖间后续所有新版本的**唯一修改、修复、开发与继承分支**。
> **禁止修改 `main`，禁止为后续迭代另开分支。** 所有新版本均在本分支持续增量修改、提交和构建；不得擅自切换开发基线。
> 旧分支只作历史参考，不作为新版本的开发基线；旧功能需先核实再决定是否移植。

## 记录规则

- 本文件只记录**开发进度**，不作为产品介绍或项目说明。
- 每完成一个功能，就在本文件对应项目下补充：**完成日期、提交号、验证方式与结果**。
- 状态区分：`待核查`、`待开发`、`进行中`、`已提交待验收`、`已验收`。
- **只有实际代码检查、测试及必要的真机验收通过，才能标记为「已验收」**；旧分支或历史记录中的“已完成”不自动算本分支完成。
- 每次推进只更新已核实的条目，保留未完成项及历史记录，不覆盖既有验收证据。

## 实施顺序

1. **核查 49 版基线**：确认现有功能、构建与数据保留边界，列出可直接复用的部分。
2. **确认新版页面目标**：确定整体结构及首页、助手列表、聊天页、设置页的布局；确认后再编码，不以旧实验版界面替代目标。
3. **逐页实现并接线**：界面与真实聊天、助手、模型和设置数据连接；每页完成后记录提交及验收结果。
4. **聊天核心优化**：逐项核查或实现缓存、回复速度、单窗口记忆、摘要生成、供应商与订阅兼容。
5. **Android 真机验收**：后台生成、通知跳转、应用锁、系统安全区与状态恢复。
6. **整体回归与 APK 构建**：验证用户数据、消息操作、模型请求、构建与安装升级。
7. **后续增强**：全局主题编辑器、情绪表情系统等按确认后的优先级推进。
