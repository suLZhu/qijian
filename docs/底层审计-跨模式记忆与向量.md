# 底层审计：跨模式记忆、向量和恢复保护

- 新增 `src/backupStorage.mjs`、`src/backupStorage.d.mts`，修改 `src/BackupCenter.tsx`、`src/backupService.mjs`：新备份记录存储模式；跨模式恢复转换记忆及密钥，保留当前连接模式，拒绝编号冲突及不能无损转换的数据。旧备份按已有字段判断来源。
- 修改 `src/backupRestore.mjs`、`src/backupRestore.d.mts`：部分和跨模式恢复后优先同步恢复的状态，防止旧后端快照覆盖本机恢复内容；对仅包含旧内部快照的同模式整体备份保留兼容。
- 修改 `src/server.mjs`、`src/server/agent/MemoryStore.mjs`：备份可读取和恢复记忆向量及模型，拒绝用其他助手的相同 ID 覆盖记忆；旧服务器不能提供已有向量时拒绝生成不完整备份。
- 修改 `src/localBackend.mjs`、`src/memoryLocalOrganize.mjs`：本机记忆保留向量模型，校验向量；达到 2000 条时明确拒绝新增，不再静默截断旧记忆。
- 修改 `src/memoryPages.mjs`、`src/memoryPages.d.mts`、`src/App.tsx`：聊天召回按需获取服务器向量，仅同一模型的向量比较。
- 修改 `src/backupIndexed.mjs`、`src/backupAttachments.mjs`：本机附件备份带 SHA-256；历史非图片附件可在本机恢复，迁往只支持图片的服务器时明确拒绝。
- 新增 `tests/backup-storage.test.mjs`；修改 `tests/android-login.test.mjs`、`tests/backup-service.test.mjs`、`tests/backup-restore.test.mjs`、`tests/backup-attachments.test.mjs`、`tests/backup-indexed.test.mjs`、`tests/backups.test.mjs`、`tests/local-backend.test.mjs`、`tests/memory-pages.test.mjs` 和 `package.json`，覆盖真实隔离服务器和本机之间的记忆/向量迁移、冲突、容量、回滚和旧快照保护。
- 626 项自动化测试通过；TypeScript 和 Web 生产构建通过；Chromium 本机 IndexedDB 备份/回滚通过。
- 局限：本机记忆上限为 2000 条；服务器图片一次备份/恢复上限 36 MiB，服务器恢复请求上限 64 MiB，超过时明确拒绝。本机旧的非图片附件不能迁入目前只支持图片的服务器。旧备份未保存的向量无法从备份中还原。Android 原生代码仍未编译/真机验证；旧记账、日记和像素主题及其余全局审计尚未完成。
