# 底层审计：服务器附件备份

- 修改 `src/server/attachments.mjs`、`src/server.mjs`：增加已登录用户的服务器图片清单和按原始 ID 的事务恢复；校验附件类型、长度、SHA-256、重复编号和已有编号冲突，异常回滚服务器事务。
- 修改 `src/backupService.mjs`、`src/BackupCenter.tsx`：服务器模式的聊天/整体备份收集并校验服务器图片；旧服务器无此能力时明确报错，不生成缺图片的成功备份。恢复前检查服务器能力。
- 新增 `src/backupRestore.mjs`、`src/backupRestore.d.mts`：先写本地和 IndexedDB，最后提交服务器事务；失败时回滚本机，网络结果不确定时提示服务器可能已更改。修改 `src/backups.mjs`，备份不再包含临时恢复标记。
- 修改 `tests/attachment-persistence.test.mjs`、`tests/android-login.test.mjs`、`tests/backup-service.test.mjs`、`tests/backups.test.mjs`，新增 `tests/backup-restore.test.mjs` 并更新 `package.json`；覆盖真实隔离服务器的鉴权、上传、备份、按原 ID 恢复、错误校验与事务回滚。
- 删除原先仅依赖页面内分散异常处理的恢复顺序，统一在恢复服务中协调本地和服务器。
- 全量 602 项通过，包含损坏附件测试。TypeScript 和 Web 构建通过；仍有大 JS chunk 警告。
- 服务器附件超过 36 MiB 或恢复数据超过 60 MiB 时会明确拒绝生成备份，需使用服务器数据库备份；本功能需新版本服务器。Android 原生代码尚未编译或真机验证；旧 APK 在首次升级前不会自动获得更新前备份。旧记账/日记、像素样式及其余全局审计仍未完成。
