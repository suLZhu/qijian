# 底层审计：辅助模型与恢复保护

## 实际修改

- `src/App.tsx`、`src/auxiliaryModel.mjs`、`src/auxiliaryModel.d.mts`：记忆整理及推理翻译共用辅助请求的用量和诊断记录。按响应线路确认来源；来源无法确认时不臆造计费。诊断只记录角色、模型及状态，不保存对话和记忆正文。
- `src/cloudRecovery.mjs`、`src/cloudRecovery.d.mts`：备份恢复后的云同步仅在服务器确认成功后清除待同步标记，失败后重新打开仍会优先重试，避免旧云端覆盖已恢复数据。
- `tests/auxiliary-model.test.mjs`、`tests/cloud-recovery.test.mjs`、`package.json`：覆盖辅助请求用量、诊断隐私、来源不明、恢复同步失败重试。

## 删除或整合

辅助模型记账与诊断统一到共享入口；恢复状态处理从 App 中抽为可测试的共享逻辑，未删除历史数据兼容代码。

## 测试和未完成事项

自动化 584 项通过；TypeScript 检查与 Web 构建通过，仍有大 JS chunk 提示。真实供应商、Android 编译及真机交互未验证。覆盖安装前自动备份未完成；现有分类/整体备份没有覆盖 IndexedDB 中的本机附件和主题素材，不能视为全数据备份。其余静态警告及全局底层扫描尚需继续。
