# 栖间 5.0+ · 唯一迭代版本

> **唯一开发分支：`feature/next-version-only`**
>
> - `main` 是 49 版稳定基线，**禁止修改主支**。
> - **禁止新建开发分支**。后续所有新版本、布局调整、修复和功能增补，都在本分支直接修改、提交、构建并持续继承。
> - 5.0 及以上版本按**整体布局重建**推进，不以旧版页面为新界面的基础。
> - `main` 与旧开发分支仅作为**可复用代码的参考来源**：少量适用的功能页或逻辑，经检查后按需提取、适配到新布局；不整页恢复旧界面、不直接合并旧分支。
> - 本 README **只记录待处理项目和验收进度**，不写产品介绍、不罗列旧版已实现功能。

## 进度更新规则

- 每完成一项，直接在本 README 更新状态，并注明完成日期、提交号、验收结果。
- 状态：⬜ 待处理 / 🟡 进行中 / 🔵 已提交待验收 / ✅ 已验收。
- **未经过实际验证，不得标记为已验收**；历史分支曾经实现，不代表新分支已完成。
- 新增需求直接补入下表，按优先级逐项推进，不另建分支或另起进度说明。
